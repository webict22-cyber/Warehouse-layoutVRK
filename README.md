# ผังคลังเม็ดพลาสติก (Warehouse Layout Dashboard)

เว็บแสดงผังคลัง (คลังประตู1 RM01–RM19 และโรง 3) บอกว่าแต่ละช่องเก็บเม็ดอะไร ปริมาณเท่าไร
ทุกคนเปิดดูผ่านเบราว์เซอร์ได้ และหน้าจอทุกเครื่องอัปเดตเองทันทีเมื่อมีคนแก้ข้อมูล (SignalR)

## ติดตั้ง
1. สร้างฐานข้อมูล `WarehouseLayout` ใน SQL Server แล้วรันตามลำดับ: `db/schema.sql` → `db/seed.sql`
2. แก้ `src/appsettings.json` : `ConnectionStrings:Db` และ `EditKey` (รหัสสำหรับคนที่มีสิทธิ์แก้ไข)
3. `cd src && dotnet run` แล้วเปิด http://localhost:5000 (ดูพอร์ตจริงในหน้าจอ console)

## หมายเหตุ
- `seed.sql` สร้างช่องจากผัง FM-WHR-01-05 พร้อมชื่อเม็ดตามที่เขียนไว้ในผัง ปริมาณยังเป็นว่าง ("?") รอนับแล้วกรอก
- ผู้ดูไม่ต้องล็อกอิน; ผู้แก้ต้องกด "ใส่รหัสแก้ไข" ครั้งแรก (เก็บในเบราว์เซอร์ของเครื่องนั้น)
- ทุกการแก้เก็บประวัติใน `StockLog`
- ยังไม่ได้ทดสอบ build/รันจริง ถ้ามี error ให้แจ้งได้
